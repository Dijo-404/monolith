# Leak Lab shell

The light guided surface preserves the owner's requested redesign: a lavender-grey page, white cards, one purple action, and an original dark route stage. The initial task is to explain direct versus private routing; detailed controls follow below it.

The four steps show a direct control, a protected fixture read, a bypass with a recomputed repair, and a managed read blocked during an outage. A bypass can continue during an outage; both the guide and checks disclose it instead of claiming that nothing leaks. Receipt requests expose a transaction hash; balance requests expose an address.

All route origins, timings, registry entries and checks in this shell are **SIMULATED**. The persistent badge, stage label and detail cards retain that provenance. Coverage stays unmeasured, payment is disabled, and no page action contacts the observer, Arkiv or an RPC endpoint. MN014 owns live composition. The shared worker/method/error vocabulary uses public `@monolith/shared` exports.

Wix Madefor Display/Text and Fragment Mono are self-hosted. Their OFL notices are beside the font files. Reduced motion is respected, all controls have readable labels, and an SVG schematic preserves the route controls when WebGL2 is unavailable. Text panels carry the same state as the stage.

The final desktop, 390px mobile, 320px narrow and WebGL fallback review is recorded in [docs/review/README.md](docs/review/README.md). Screenshots represent the fixture shell, never live network evidence.
